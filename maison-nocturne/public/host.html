How to run the event
  1. Run the museum server on one computer; keep it awake. Use the phone-reachable Wi-Fi address or a public deployed URL.
  2. Create an event for 50 participants. Share its QR or join link. Names must be unique.
  3. When all 50 join, press Start Room 1. Everyone’s clock starts together.
  4. Results appear when all active players finish, or after you explicitly close the round. Unfinished players do not qualify.
  5. Review the top 30 and start Room 2. Repeat for 15, then 5, then one winner.
  6. Only qualified sessions can submit evidence or answers in later rounds. Do not close early unless you intend to exclude unfinished participants.

This is a classroom competition, not a tamper-proof examination. Use a stable shared network. Times are server receipt times, so network delays count. Reloading does not restart a participant’s clock.
